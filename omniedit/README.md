# 随心编辑器

飞牛原生文本编辑器，一个工具覆盖 NAS 上的代码、配置、Markdown 与富文本编辑场景。

## 特性

- 大文件异步分批加载，主线程零阻塞；编辑上限可调（5–20MB）
- 二进制 / UTF-16 / GB18030 自动识别与转码
- 语法高亮 42 语言族 / 120+ 扩展名，按文件内容判定
- 多标签页（拖拽排序、批量关闭）、查找替换、代码折叠
- Markdown / HTML 实时预览，相对路径资源自动重写
- 会话恢复 + mtime 冲突检测 + 外部变更 WebSocket 推送
- 移动端窄屏专属布局，安全区与触控目标全面适配
- 路径穿越与符号链接逃逸防护，文件写入原子化

## 安装

- fnOS **1.2.0+**，全平台（x86_64 / arm64）
- FnDepot 中添加应用源直接安装
