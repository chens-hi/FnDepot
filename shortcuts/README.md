# 快捷图标

飞牛 fnOS 原生应用：把局域网服务的端口/路径、或 NAS 上的文件夹，变成飞牛桌面上的原生快捷图标，双击直达。

## 三种快捷入口

| 类型 | 填写内容 | 生成结果 |
| --- | --- | --- |
| 内置端口 `internal_port` | 映射端口、协议（http/https）、访问路径、打开方式 | 独立子应用，打开时访问 `协议://当前地址:端口/路径` |
| 外部链接 `external_url` | 目标地址、打开方式 | 独立子应用，启动时跳转到目标地址 |
| 文件夹 `folder` | 文件夹绝对路径（可浏览选择或手动输入） | 不安装子应用，直接在桌面创建原生文件夹项 |

打开方式有两种：桌面内嵌（作为应用窗口打开）和新标签页。

## 安装

- 要求 fnOS **1.2.0 及以上**，架构 `x86`（amd64）或 `arm`（arm64）。
- 需要管理员账号，安装时会申请文件夹访问权限。
- 两种方式任选：
  1. 在 FnDepot 中添加本仓库作为应用源，直接安装；
  2. 下载 [`fpk/`](./fpk) 下对应架构的 `shortcuts-<版本>-linux-<arch>.fpk`，在「应用中心 → 手动安装」中选择。

## 使用

1. 打开「快捷图标」→「新增配置」，先选类型再填字段；唯一标识创建后不可修改。
2. 保存只写入配置，端口/链接类型点「部署」，文件夹类型点「创建」。
3. 桌面出现图标后双击使用；改配置后列表显示「待更新」，再点一次「更新」即可。

字段约束：

- 唯一标识：2–12 位，以小写字母开头，只含小写字母、数字和连字符。
- 捷径名字：最多 12 个字符。
- 文件夹路径：必须是 NAS 上的绝对路径，保存时以 root 校验真实存在且是目录。

## 注意事项

- 文件夹快捷方式需要在飞牛桌面内打开「快捷图标」才能创建，浏览器独立标签页拿不到桌面宿主接口。
- 删除条目或卸载应用都不会删除文件夹里的内容。
- 配置与日志位于 `/usr/local/apps/@appdata/shortcuts/`。
